# 🔌 Switch-to-Switch Network Project

## 📌 Overview

This project demonstrates how to connect two switches using Fast Ethernet ports in Cisco Packet Tracer.

## 🛠️ Tools Used

* Cisco Packet Tracer

## 🔗 Topology

* Switch1 (Fa0/1) connected to Switch2 (Fa0/3)

## ⚙️ Configuration

* Enabled interfaces using `no shutdown`
* Verified status using `show ip interface brief`

## 📊 Output

* Interfaces are in **up/up** state
* IP address shows **unassigned** (normal for switch ports)

## 🧠 Concept

Switches operate at Layer 2 and use MAC addresses instead of IP addresses.
